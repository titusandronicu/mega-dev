- Thirty offline tests with fakes were green while round 1 failed `followup_forgot`: the agent handled each mail alone, so Rook's follow-up "who enqueued it?" got "no record". Fakes repeat your own assumptions. Replay the round's shape (follow-up, expired page, stranger in the middle, injection bait) through the real code and the real model with a simulated mailbox, and claim only when every run passes. [evidence: claim 3 reply, `agent/evals/rehearse.mjs` 21 of 21 runs clean on the NAS] [fix: tool] [status: applied] [idea: rehearse-the-shape]
- A follow-up must not depend on fetching the page again. The agent now keeps every page it read per thread (SQLite on the NAS, cut at 6000 characters) and loads the thread's earlier messages; in rounds 2 and 3 the follow-up used 2 history messages and 1 saved page and made no fetch. Decide a memory's scope, store and lifetime on purpose. [evidence: journal `history 2, pages 1`, rehearsal scenario B (page expired)] [fix: tool] [status: applied] [idea: write-down-state]
- A requested format lived only in the prompt, and the first reply added a time the page did not show (03:49:38 against 03:50:55). Detect "ANSWER: <x>" in code and send only that line; the first detector anchored the marker to the line start and missed Rook's real wording "one line again: ANSWER: <enqueuer>", and only a test with the real mail text caught it. What code can enforce, code should enforce. [evidence: round 1 reply, `agent/test/guard.test.mjs` answer-line test] [fix: tool] [status: applied] [idea: code-over-prompt, source-over-summary]
- A stranger in the thread (`team@mail.mega.dev`, "rook said you'd have this open") gets no reply, no fetch and no place in the model's context: the sender is compared by exact address in code before the model runs, and an earlier stranger mail enters the history only as a "content withheld" marker. Look-alike addresses and display-name tricks fail the comparison. [evidence: journal `ignored` in all three rounds, rehearsal scenarios C, F, G, H] [fix: tool] [status: applied] [idea: distrust-decoys, code-over-prompt]
