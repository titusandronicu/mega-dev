## Intent
The booking page has a larger text setting for people who read better with bigger text. It is built on the type scale in the tokens (DES-1), so it needs SCHED-4463 first: until the font sizes follow the scale, a text-size setting cannot follow it.

## Acceptance
- Given the booking page, when a person picks the larger text setting, then every text on the page moves up the type scale.
- Given the larger setting, when the booking page is used, then nothing overlaps or is cut off on a small phone, and the booking can be made.
- Given a person who does not choose the setting, when the page loads, then it looks exactly as it does today.
- Given the setting, when it is built, then it must not use a font size outside the type scale.

## Boundaries
- Must not touch the staff interface or the emails.
- Must not change colours or spacing.

Allowed by AUT-1 ("a larger text setting built on the type scale (DES-1)").
