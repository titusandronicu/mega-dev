## Intent
The staff can search the bookings list by booking reference as well as by name.

## Acceptance
- Given a booking with reference `ABC1234567`, when staff search that reference, then the booking is in the results.
- Given a search by name, when it runs, then it returns what it returned before (accents still match).
- Given a reference that does not exist, when it is searched, then the list is empty and shows no error.
- Given a partial reference, when it is searched, then it must not match every booking.

## Boundaries
- Must not change booking references or how they are made (that is IN-6239).
- Must not remove or change the name search.

Allowed by AUT-1 ("new columns, filters or fields that add to what is there and take nothing away").
