## Intent
The day view gets a print button. The front desk prints the day's bookings every morning (IN-4109).

## Acceptance
- Given the day view, when staff press the print button, then the browser's print dialog opens with the day's bookings (time, name and slot).
- Given the printed page, when it is shown, then it holds only the bookings, with no menus, buttons or other screen parts.
- Given a day with no bookings, when staff press print, then the page says there are no bookings and does not fail.
- Given the print button, when it is added, then it must not change the day view on screen or any existing button.

## Boundaries
- Must not change stored data or add an export.
- Must not print on the public booking page; the day view is for staff.

Allowed by AUT-1 ("new columns, filters or fields that add to what is there and take nothing away").
