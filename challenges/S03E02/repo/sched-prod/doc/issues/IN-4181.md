## Intent
The booking form gets an optional short note field, for things like "first visit" or "bring a mat" (IN-4181) or what hurts before a session (IN-3041). The staff see the note on the booking.

## Acceptance
- Given the booking form, when a person leaves the note empty, then the booking is made as today.
- Given a note of up to 500 characters, when the booking is made, then the note is saved with that booking and shown to the staff on the booking.
- Given a note of more than 500 characters, when the person submits, then the form shows an inline error next to the field and does not save (DES-4).
- Given an export, when it is produced, then the note is a new column and every column it had before is still there (PRD-3).
- Given a note with HTML or script in it, when it is shown, then it appears as plain text and must not run.
- Given a note, when the booking page is public, then the note must not be shown to anyone but the staff of that account.

## Boundaries
- Must not change or remove any existing field of the booking form.
- Must not make the note required.

Allowed by AUT-1 ("new columns, filters or fields that add to what is there and take nothing away").
