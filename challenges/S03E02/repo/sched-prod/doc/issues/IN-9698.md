## Intent
The CSV export quotes fields correctly, so a comma, a quote or a line break inside a value no longer moves the columns.

## Acceptance
- Given a client name `Smith, Jones & Co`, when the export is produced, then the row has the same number of columns as the header and the name is in one column.
- Given a value with a double quote, when it is exported, then the quote is doubled inside a quoted field.
- Given a value with a line break, when it is exported, then it stays in one field.
- Given values with no special characters, when they are exported, then they must not change from today.

## Boundaries
- Must not change column names, order or date format.
- Must not drop or rename any column (PRD-3).

Allowed by AUT-1 ("bug fixes and small features inside the specs, with a test that shows the change").
