## Intent
The "Cancel" button on the booking page says "Cancel booking", so people do not think it only closes the dialog. This follows DES-5: a verb and its object.

## Acceptance
- Given the booking page, when the cancel button is shown, then its label reads "Cancel booking".
- Given the button, when it is pressed, then it works exactly as before.
- Given a button that only closes a dialog, when it is shown, then it keeps its own label and must not be renamed to "Cancel booking".
- Given the change, when it is done, then it must not change any other text, behaviour or key.

## Boundaries
- Must not touch other buttons or the emails.
- Must not change what the button does.

Allowed by AUT-1 ("copy changes in the product's own interface").
