## Intent
A person can pick a date on the booking page with the keyboard alone.

## Acceptance
- Given the date picker, when a person tabs to it, then it takes focus and the focus is visible.
- Given the picker is open, when the person uses the arrow keys, then the focused date moves, and Enter selects it.
- Given the picker is open, when the person presses Escape, then it closes and focus goes back to the field.
- Given a mouse user, when they use the picker, then it works exactly as before and must not lose any behaviour.

## Boundaries
- Must not change how dates are stored or parsed (PRD-2).
- Must not add a modal for errors (DES-4).

Allowed by AUT-1 ("bug fixes and small features inside the specs, with a test that shows the change").
