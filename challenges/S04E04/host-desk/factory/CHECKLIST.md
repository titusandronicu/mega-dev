# Checklist

1. Bind each secret to the hosts it may reach, in code, and check every hop, redirects included.
2. Run routine work as a script; the model decides only what the script cannot.
3. Turn the rules in any document you read into checks, and park the owner’s calls instead of making them.
4. Have every role read its facts (settings, prices, limits) from their source at every start; never copy them into its files.
5. Write down why each decision exists, next to the code, and have every role read those notes before it judges or changes anything.
6. Plan by files before anyone works: one owner per file, and a file every change needs goes to one integrator.
7. Send every unclear request to a critic first, and let the owner answer before any code changes.
8. Handle each event once: keep its id and body hash; skip a repeat, send a changed repeat to the owner.
9. Every running job has an owner among your roles; stop the others by job id before the night, and read the whole API listing first.
10. When an event names no clear target, change nothing and park it for the owner. After a denied call, hand the owner a script; do not retry.
